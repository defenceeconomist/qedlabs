Integrity and licences#

Run ./verify.sh to verify the book-level checksums.sha256 file and the dataset hashes embedded in data/manifest.json. Redistribution notices and upstream licences are retained in the bundled data/provenance/ directory.

The HISP snapshot also retains its original Stata file and replication script for provenance. The notebooks execute the R lab and do not run that script.
