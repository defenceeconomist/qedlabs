# Difference-in-differences guide

## Use this section when

Some units experience a treatment change while other credible units do not, and
repeated outcome observations make the untreated change—not merely untreated
levels—a plausible comparison.

## What this adds to Module 6

The section begins with the familiar two-group, two-period contrast, then develops
staggered adoption, treatment-effect heterogeneity, problematic already-treated
comparisons, group-time effects, event studies, controlled aggregation, and
sensitivity to violations of parallel trends.

## Recommended sequence

1. **Methods report:** define the counterfactual change and target effect.
2. **Foundations:** calculate the four-cell contrast and recover it by regression.
3. **Staggered diagnostics:** inspect cohorts, untreated support, TWFE decomposition,
   and event-study behaviour.
4. **Modern estimators:** estimate and aggregate group-time effects and compare
   control groups and sensitivity assumptions.

## Completion check

You should be able to describe parallel trends as a counterfactual claim, explain
why pre-trend evidence is informative but not decisive, identify forbidden or
misweighted comparisons, choose an aggregation that matches the estimand, and
state the clustering and uncertainty strategy.
