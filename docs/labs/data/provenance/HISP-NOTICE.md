# HISP Teaching Materials

Source: World Bank and Inter-American Development Bank, *Impact Evaluation in
Practice*, second edition, HISP case study.

https://www.worldbank.org/en/programs/sief-trust-fund/publication/impact-evaluation-in-practice

The original `evaluation.dta`, `evaluation.csv`, and `HISP Book replication.do`
were recovered byte-for-byte from this repository's commit `3152e4d`.
The RDS is a lossless column-value snapshot of the CSV; the original Stata labels
are transcribed in `hisp.txt`. These files are accompanying educational materials,
not a new study dataset collected by QED Labs.

The source page supplies the code and data without a guarantee that they will
run on every computer or yield expected results. It disclaims responsibility
for adverse effects from their use. Retain this attribution and consult the
source's terms for further reuse; QED Labs asserts no additional license over
the original materials. The original Stata script is archival and is not invoked
by the offline R workflow.
